# 章节完成检查清单

每章进入 `reviewed` 前必须完成：

- [ ] 章节标题、状态、剧透级别、时间范围齐全。
- [ ] 关键事件有事件卡或来源卡支撑。
- [ ] 关键人物经历有人物卡或来源卡支撑。
- [ ] 关键组织行动有来源支撑。
- [ ] 时间顺序清楚；不确定顺序已标注。
- [ ] 推测、解读、社区观点已明确标注。
- [ ] 没有大段复制原文、Wiki 段落或剧情文本。
- [ ] 引文短且必要。
- [ ] 术语与 `notes/terminology.md` 一致。
- [ ] 章节末尾列出主要来源。
- [ ] 未确认点已列出。
- [ ] 更新 `notes/timeline.md`。
- [ ] 更新 `logs/progress.md`。
