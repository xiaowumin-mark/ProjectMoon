summary: >
  《The Distortion Detective》（扭曲侦探）是一部由Project Moon在POSTYPE平台上官方发布的网络小说，
  于2020年2月29日开始连载。截至中止前，该作品共完成了42章正文和1话漫画试作（第19章的漫画改编）。
  Project Moon官方表示，由于更倾向于在完成《Limbus Company》之后将《扭曲侦探》改编为游戏，
  因此中止了该网络小说的连载。中止后的章节仍可在POSTYPE上访问，但故事的主线并未完结。
  这一中止与Project Moon从文字/漫画类衍生作品向游戏开发聚焦的战略转向一致——
  同期，《Leviathan》的英文翻译也因翻译团队转向《Limbus Company》发布准备而中止。
  至于《扭曲侦探》是否会以游戏形式回归，以及回归后的具体形式和发布日期，
  截至2026年6月24日，Project Moon尚未发布正式的后续公告（待官方公告确认）。
causes:
  - Project Moon决定在完成《Limbus Company》后将《扭曲侦探》开发为游戏。
  - 开发资源集中于《边狱公司》的持续运营和内容产出。
process:
  - 2020年2月29日：《扭曲侦探》第1章在POSTYPE发布。
  - 2020年至中止前：共发布42章正文和1话漫画试作。
  - Project Moon宣布中止连载，表示倾向于将其改编为游戏。
  - 现有章节保留在POSTYPE上可供访问。
outcomes:
  - 《扭曲侦探》故事主线未完结。
  - 摩西、以斯拉等角色和扭曲侦探事务所的概念成为Project Moon宇宙的组成部分。
  - 部分角色（如以斯拉）在边狱公司中以人格（Identity）形式被引用。
long_term_impact:
  - 截至目前，尚无关于《扭曲侦探》游戏化的具体进度或发布日期信息。
  - 中止前的章节成为理解Project Moon宇宙中扭曲现象调查机制的重要官方资料。
